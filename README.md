# Программа решения квадратных уравнений

Предназначена для исследования квадратичных функций и их решения.

## Установка

Для установки нужно склонировать репозиторий проекта с github, после чего скомпилировать main.cpp для основных функций, либо create_random_tests.cpp для создания случайных тестов.

`git clone https://github.com/Gorox509/Square-equation-solver.git`

`g++ code/main.cpp -o square_solver.exe`
`g++ code/create_random_tests.cpp -o random_tests.exe`

После компиляции для запуска программы достаточно запустить полученный исполняемый файл.

`./square_solver.exe`

## Руководство пользователя

Программа поддерживает 2 режима работы: обычный и режим тестирования. По умолчанию при запуске программы она запускается в обычном режиме. Для запуска в режиме тестирования нужно указать флаг -t при запуске программы.

После запуска программы пользователю будет предложено ввести символ-команду, который вызовет соответствующие функции.
Список доступных команд:
- **s**: Переход к решению квадратного уравнения. Будет предложено ввести коэффициенты уравнения через пробел. В случае некорректного ввода у пользователя будет до 10 попыток ввода до того, как программа вернется в меню.
- **p**: Отрисовывает символьный график данных квадратичных функций. Пользователь должен указать, в какой файл (или ни в какой, то есть в консоль) необходимо осуществить отрисовку, количество функций для отрисовки, высоту и ширину холста (в выводимых символах) и, наконец, коэффициенты нужных функций. Затем осуществится отрисовка, после чего управление вернется в меню.
```
Пример графика
     #     # #       |       #           
     #       # #     |       #           
     #         # #   |       #           
     # #         # # |     # #           
       #           # #     #             
       #             #     #             
       #             # #   #             
       #             | # # #             
       # #           |   # #             
         #           |   # # #           
 - - - - # - - - - - 0 - # - # # - - - - 
         #           |   #     #         
         # #         | # #     # #       
           #         | #         # #     
           #         | #           # #   
           # #       # #             # # 
             #       #                 # 
             # #   # #                   
               # # # |                   
                     |         
```    
- **c**: ***Осторожно!!! Не вызывать ни при каких обстоятельствах!***

В режиме тестирования также становятся доступны дополнительные фунции:
- **t**: Произвести тестирование решающей программы из введенного файла. После работы будет выведена информация о проваленых тестах, а также статистика по всем тестам файла.
- **f**: Произвести тестирование программы, решающей уравнения и выводящей ответ в определенном формате. Будет предложено ввести имя тестового файла, после чего выполнятся тесты. Для каждого проваленного теста будет выведена его информация, в конце выведется статистика по всем тестам.


Для создания случайных тестов в программу будет предложено ввести файл назначения, количество тестов и количество корней в них.

### Запланированные изменения

- Для графиков будет добавлено масштабирование и смещение, нумерация и подписи осей.
- Для создания случайных тестов планируется расширение опций количества корней и улучшение алгоритма генерации.

### Известные проблемы

- Генерация случайных тестов часто записывает ответы, не совпадающие с реальными из-за проблем округления.
- Вывод графика в консоль может занимать продолжительное время
- Для отрисовки графика может использоваться избыточная память
